# Delta

Control [Delta](https://delta.dev), the agent-first coding app from Zed Industries, from Raycast.

## Commands

- **Search Threads**: find threads by title, summary or keyword. Open them in Delta or on delta.dev, copy their link, share them with your organization, or archive them.
- **Create Thread**: start a thread with a draft prompt in the organization and visibility you choose. Delta opens it so you can review the prompt and send it.
- **Open with Delta**: open the selected Finder item, or the front Finder folder, in Delta.
- **Ask Past Threads**: ask a question and get an answer drawn from your past threads.

## Requirements

- The Delta desktop app, signed in to your account. The extension uses the `delta` CLI bundled inside the app, so you don't need to install the CLI separately.
- Ask Past Threads uses a model through your Delta account, so it needs model access in Delta.
